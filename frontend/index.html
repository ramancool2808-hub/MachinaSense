About this workspace

A responsive frontend with a local FastAPI backend.

Architecture

Browser UI → FastAPI endpoints → CSV inspection, scikit-learn training, joblib persistence, and prediction.

GET /api/healthService status
POST /api/dataset/previewInspect CSV
POST /api/trainTrain classifier
POST /api/predictRun inference
GET /api/modelModel metadata

Upstream reference

This interface is inspired by the public MachinaSense architecture. Its full backend includes authenticated multi-tenancy, database records, training jobs, registry/versioning, inference history, RAG and a copilot. This lightweight local edition implements a subset for dataset inspection, training and inference; it does not claim to reproduce every upstream function.
